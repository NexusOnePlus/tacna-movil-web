# Instrucción inicial

Se necesita crear un embebido para celular Android que sea una aplicación muy pequeña cuya unica funcionalidad es, mediante redes moviles, enviar la ubicación actual del dispositivo en tiempo real, más unos datos adicionales para verificar la identidad del dispositivo, que correponde al ID que se le instalo junto a la aplicación.

Para ello se pide crear una nueva carpeta en el proyecto donde se guardara los archivos de la app que luego seran utilizados para generar el apk que utilizara el dispositivo Android.

La aplicación del celular debe ser muy pequeña, para que los usuarios no tengan problemas para instalarlo ni les quite bastante almacenamiento. Se pide que pese menos de 50MB, aunque todavia se evalua si eso es siquiera posible.

No es necesaria una UI pulida, pues su utilidad es meramente funcional, más su prioridad no es ser interactuable ni navegable.

Además, se pide que al iniciar la aplicación inmediatamente solicite encender la ubicación + los permisos. A partir de lo cual se minimiza a segundo plano para no interrumpir las actividades del usuario.

Se pide además, que debido a la poca información que va a transmitir, sea veloz la transmisión pues se tratan de datos en tiempo real, para lo cual se aplicara los protocolos de red necesarios.

Si se necesita apoyo para resolver dudas sobre desiciones de diseño o arquitectura, porfavor preguntar antes de... Además conservar este mensaje como la instrucción inicial de lo que se debe hacer.
